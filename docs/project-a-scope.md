# OfferFlow MVP 范围

## 目标用户

- 正在寻找日常实习、暑期实习、秋招或春招岗位的本科生和研究生。
- 第一版重点验证软件、AI 和数据方向的求职学生，优先深圳、广州。
- 用户通常同时跟踪 5–20 个岗位，使用招聘平台收藏、Excel、备忘录或聊天软件记录。

## 核心用户流程

1. 用户粘贴岗位描述，系统提取岗位信息并创建投递记录。
2. 用户通过 Agent 更新投递状态，系统管理截止日期、待办和状态历史。
3. 系统对照岗位要求检索简历与项目证据，输出匹配结果和技能缺口。
## MVP 必须做

- 粘贴并解析岗位描述，提取公司、岗位、城市、截止时间和技能要求。
- 创建、查询、修改和删除个人投递记录。
- 保存投递状态历史，拒绝非法的状态流转。
- 查询即将截止和长期无回复的岗位。
- 保存一份主简历及其项目证据。
- 根据岗位要求查找相关证据，输出“满足、部分满足、缺失”。
- 为测评、面试和跟进创建任务，并展示今日待办。
- 通过 Agent 对话调用岗位、状态、截止和证据匹配工具。

## 暂不做

- 招聘网站爬虫和全网岗位搜索。
- 自动提交申请。
- 自动联系 HR。
- 招聘录用概率预测。
- 自动编造经历或复杂简历美化。
- 多用户公开注册和企业招聘后台。
- 完整登录、组织权限和租户隔离。
- 大规模知识库、BM25 与向量混合检索、Cross-Encoder 重排。
- 多智能体协作。
- 短信、邮件和微信主动通知，第一版只做站内待办。

## 成功标准

- 用户能粘贴岗位并创建投递记录。
- 用户能用自然语言更新投递或面试状态。
- 系统能发现即将截止和长期无回复的岗位。
- 系统能给出带简历证据的匹配结果和技能缺口。
- Agent 能创建准备或跟进任务。
- 3–5 名求职用户愿意持续试用。
