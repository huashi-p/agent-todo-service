# OfferFlow Week 9 MVP 冻结

冻结日期：2026-11-06

## 唯一核心流程

用户粘贴岗位 JD
→ 解析并由用户确认
→ 创建投递记录
→ 保存简历或项目证据
→ 匹配岗位要求
→ 显示证据和技能缺口
→ Reflection 检查匹配结果
→ 生成准备任务草稿
→ 用户确认后保存任务

## 本周保留

- 岗位 JD 结构化解析
- 投递记录创建与查询
- 状态机和状态历史
- 截止查询和长期未跟进查询
- 简历与项目证据切分
- 证据排序、去重和引用
- matched、partial、missing 匹配状态
- Reflection 确定性检查
- 准备、跟进、测评和技能补强任务
- 准备计划草稿与用户确认
- Agent 对话、上下文历史和 SSE

## 本周不做

- 招聘网站爬虫
- 自动投递或自动联系 HR
- 多用户注册和登录
- 企业招聘后台
- 自动邮件、短信和微信通知
- 多智能体
- 复杂向量数据库和 Cross-Encoder
- 复杂任务看板

## 工程底座

以下能力保留，但不作为产品主流程展示：

- User 和 Todo CRUD
- Redis Todo 缓存
- Docker Compose
- PostgreSQL
- Nginx 和部署配置

## 成功标准

- 用户只使用页面和自然语言就能完成核心流程。
- 匹配结果能追溯到证据原文。
- 没有证据的岗位要求会标为 missing。
- Reflection 能发现状态与证据不一致的结果。
- 用户确认后任务能持久化并查询。
- 外部用户试用将在 Day 63 完成，当前不能宣称已有真实用户反馈。
